# Edge test plan — 0.0.10 first integrated build

Target: Edge + Violentmonkey.

## Purpose

Validate the first single-script 0.0.10 build after integrating the WebM/video hidden native timeline logic that was previously proven with the bridge probe.

## Setup

- Enable only `google-drive-folder-player.user.js` version 0.0.10.
- Disable the 0.0.9 main script if Violentmonkey kept it as a separate entry.
- Disable all WebM diagnostic/bridge probe scripts.
- Refresh Google Drive before testing.

## Test sequence

1. Open the same mixed MP3/WebM Drive folder used for the 0.0.9 tests.
2. Leave the Drive right-side Details/Information pane open for one run, because 0.0.10 should no longer mistake it for an active preview.
3. Click `Scan folder view` and confirm the expected visible/cached media count.
4. Click `Start continuous test`; confirm track 1 opens and plays.
5. Click `Next now`; confirm track 2 (WebM in the current test folder) opens normally.
6. Confirm the green state line eventually reports progress via `hidden native range` while the WebM controls are hidden.
7. Seek the WebM close to the end and let it finish naturally.
8. Confirm automatic transition to track 3.
9. Click `Next now` several more times to confirm ordinary transition stability remains comparable to 0.0.9.

## Expected result

- No separate bridge script is required.
- MP3 and WebM/video progress are both detectable.
- WebM natural end triggers automatic next-track playback.
- An open right-side Details pane does not block preview close/reopen transitions.
- 0.0.9 transition reliability and approximate speed are preserved.
