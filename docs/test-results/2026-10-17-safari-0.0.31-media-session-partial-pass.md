# Safari + Userscripts — 0.0.31 Media Session partial PASS

Date: 2026-10-17

## Owner result

0.0.31 materially improved macOS system media integration.

PASS:

- Mac media keys can control the Google Drive player even when another application is in the foreground.
- Play/Pause works.
- Next works.
- Previous works.
- macOS Now Playing now shows the current Google Drive track title.
- System controls render as Previous / Play-Pause / Next rather than generic ±15 second seek buttons.

FAIL:

- macOS Now Playing progress remains stale/frozen instead of advancing in real time.

## Interpretation

The Media Session action routing and metadata ownership problems are now resolved enough for system controls to target this player reliably.

The remaining issue is isolated to Now Playing position presentation.

## Next experiment

Preserve the successful 0.0.31 metadata/action ownership behavior, but stop overriding playback position through `MediaSession.setPositionState()`.

Allow WebKit to derive and periodically publish Now Playing position directly from the active HTMLMediaElement.

This isolates whether the explicit Media Session position state is preventing or conflicting with Safari's native media-element progress reporting.
