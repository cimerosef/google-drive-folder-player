# Edge + Violentmonkey — 0.0.22 direct media core PASS

Date: 2026-09-16

## Result

The mixed direct-media core probe passed after the 0.0.2 promoted-slot role fix.

Validated on Edge + Violentmonkey:

- MP3 -> MP3 direct transition: pass.
- MP3 -> WebM direct transition: pass.
- WebM -> MP3 direct transition: pass.
- WebM -> WebM direct transition: pass.
- Natural-end transitions after seeking current media to the last ~5 seconds: pass.
- `Next now`: pass.
- One-next-track preload promotion: pass.
- Background-tab playback and mixed-format transition: pass.
- No Google Drive Preview opened during direct MP3/WebM playback.

Observed transition latencies in the successful run were in the low-millisecond range after preload promotion.

## Bug fixed during validation

Probe 0.0.1 attached end-of-track behavior to the slot's original role (`next` versus `current`). A preloaded slot promoted to current therefore did not automatically advance after it ended.

Probe 0.0.2 changed the decision to use the slot's live identity (`currentSlot === slot`) and updates the promoted slot role. The mixed queue then advanced correctly across all MP3/WebM boundaries.
