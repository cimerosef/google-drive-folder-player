# Edge test plan — 0.0.14 full-folder discovery probe

Target: Microsoft Edge + Violentmonkey

## Purpose

Validate a discovery-only probe that traverses Google Drive's virtualized folder list and determines whether media discovery converges without requiring the user to know the real file count beforehand.

## Setup

- Keep the validated main player script 0.0.13 available, but disable it during this probe test to avoid two panels and unrelated playback activity.
- Enable only `probes/full-folder-discovery-probe.user.js` version 0.0.1.
- Open the target Google Drive music folder.
- Close any open Drive file preview before starting.
- List view is preferred for this first probe.

## First scan

1. Click `Run full scan`.
2. Let the probe move through the folder automatically. Do not manually scroll while it is running.
3. Observe the live counters: pass number, unique media count, stable Drive-ID coverage, scroll position, bottom state, and stable-bottom count.
4. Wait until the probe stops by itself.
5. A successful first scan should report:
   - `Bottom reached: YES`
   - `Stable bottom passes: 5/5`
   - `Result: DISCOVERY CONVERGED`
6. Record the reported unique media count and stable-ID count.

## Independent verification scan

1. Without changing the folder contents, click `Verify scan again`.
2. Let the second scan complete independently from top to bottom.
3. The strongest expected result is:
   - second scan also reports `DISCOVERY CONVERGED`
   - `Verification vs first scan: EXACT MATCH`
   - `Missing from verification: 0`
   - `New only in verification: 0`

The two scans do not need the user to know the true music-file count in advance. Reaching the bottom, observing several zero-growth passes with stable scroll height, and reproducing the exact same discovered key set on an independent second scan together provide the convergence evidence.

## Small known-count cross-check (optional but preferred before integration)

Create or use a small temporary Drive folder containing a known number of media files, for example 10–20 files. Run the same two-scan procedure there and confirm the discovered count equals the known count and both scans match exactly.

## Failure / diagnostic cases

Share the full probe panel if any of these occur:

- the count stops increasing but `Bottom reached` remains `NO`;
- the scan reaches the maximum pass limit without convergence;
- stable Drive-ID coverage is significantly below the total discovered count;
- the second scan converges to a different key set;
- the probe appears to scroll the wrong region of the Drive page;
- the page becomes stuck or repeatedly jumps between positions.

## Scope

This probe does not modify the main player's queue logic. It only discovers and counts media items while scrolling the Drive folder. Integration into Shuffle/Repeat playback is a later step after the discovery behavior is validated.
