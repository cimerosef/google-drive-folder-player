# Edge + Violentmonkey — 0.0.26 transport UI test plan

Date: 2026-09-16

## Scope

0.0.26 remains a UI/control iteration on top of the validated 0.0.24 playback/discovery core. This revision combines minimize/restore, Pause/Resume, Previous, and a dedicated transport-control row.

## Intended behavior

- normal panel separates folder/settings controls from playback transport controls;
- transport row uses icon buttons only: `⏮` Previous, `⏸` / `▶` Pause/Resume, `⏭` Next;
- manual Previous and Next ignore Repeat ONE and actually move through the current queue;
- at queue boundaries, Repeat ALL wraps Previous/Next, while Repeat OFF/ONE does not;
- minimized bar keeps Previous, Pause/Resume and Next directly accessible without restoring the full panel;
- minimizing/restoring must not interrupt playback or rebuild the queue;
- Stop remains distinct from Pause: Stop releases current/preloaded media, Pause preserves position and queue state.

## Checks

1. Scan the reference folder and confirm 160 tracks are still found.
2. Start playback and use `⏭`, then `⏮`; confirm the queue moves forward and back one track.
3. Pause with `⏸`, wait several seconds, resume with `▶`, and confirm playback resumes from the same position.
4. Repeat the Previous/Pause/Next controls while the panel is minimized.
5. Confirm Repeat ONE does not trap manual Previous/Next on the same track.
6. Confirm Repeat ALL wraps Previous from track 1 to the last track and Next from the last track to track 1.
7. Confirm one MP3/WebM transition and one background handoff remain stable.
8. Confirm minimize/restore and dragging remain smooth.

## Non-goal

No changes to full-folder discovery, direct-media URL construction, preload strategy, Shuffle algorithm, or natural-end Repeat behavior.
