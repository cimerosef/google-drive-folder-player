# Edge validation — 0.0.11 Shuffle PASS

Platform: Microsoft Edge + Violentmonkey
Date: 2026-09-13

## Result

The first 0.0.11 shuffle build passed the manual validation on the existing mixed-media Google Drive folder.

Confirmed behavior:

- Folder scan returned the expected cached media list.
- `Shuffle: ON` generated a randomized fixed queue.
- The first opened track matched queue item 1.
- Repeated `Next now` actions followed the displayed shuffled queue in order.
- Track transitions remained stable and responsive, subjectively as smooth as the validated 0.0.9/0.0.10 transition path.
- Automatic end-of-track advance also followed the next item in the same shuffled queue.
- MP3/WebM mixed-media playback remained functional while Shuffle was enabled.
- The current queue stayed fixed during playback rather than being re-randomized on each transition.

## Conclusion

0.0.11 preserves the validated continuous-playback core and adds a working one-pass shuffled queue for the currently cached media items. Shuffle itself introduces no repeats; Repeat modes remain a separate later feature.
