# Edge test plan — 0.0.18 direct MP3 core probe

Target: Microsoft Edge + Violentmonkey
Date: 2026-09-16

## Purpose

Validate that the proven two-track direct-MP3 technique scales to a real multi-track queue before changing the main player.

This probe intentionally excludes Shuffle, Repeat, WebM and full-folder discovery. It tests only the new direct MP3 playback core:

- scan currently visible MP3 rows and stable Drive IDs;
- play MP3s without opening Drive Preview;
- keep exactly one next MP3 preloaded;
- promote the preloaded Audio element on natural end or manual Next;
- continue to preload the following MP3;
- remain functional while the Drive tab is in the background.

## Setup

- Disable the normal `google-drive-folder-player.user.js` main player for this test.
- Disable older MP3/File-ID/two-track probes.
- Enable only `probes/direct-mp3-core-probe.user.js` from `dev/0.0.18-direct-mp3-core`.
- Refresh the Drive Music folder.

## Foreground multi-track test

1. Click `Scan visible MP3s`.
2. Confirm the queue contains several MP3 tracks.
3. Click `Start direct queue`.
4. Confirm no Drive Preview opens.
5. Let track 1 play briefly. The next track should reach `canplay` in the log.
6. Click `Seek current to last 5s` and allow natural completion.
7. Confirm track 2 starts smoothly.
8. Repeat for at least tracks 2→3 and 3→4.
9. Confirm the queue position advances exactly one item each time and no track is duplicated/skipped.

## Manual Next test

- While a track is playing, click `Next now`.
- The current Audio should stop and the already-preloaded next Audio should become current when available.
- The following track should then begin preloading.

## Background test

1. Start the direct queue.
2. Seek the current track to the last 5 seconds.
3. Switch to another browser tab before it ends.
4. Leave Drive in the background for at least two natural transitions if practical.
5. Confirm audio continues and each next MP3 starts normally without returning to Drive.

## Expected diagnostics

Useful log lines include:

- `Preload requested for next track ...`
- `next ... canplay`
- `Promoting preloaded track ... to current.`
- `Direct transition audible-start latency: ... ms.`

## Pass criteria

- No Google Drive Preview UI is used for MP3 playback.
- At least 3 consecutive natural MP3 transitions succeed.
- The next track is already preloaded before each transition.
- Background transitions continue normally.
- Manual Next works.
- No unexpected track skips or duplicates.

If this probe passes, the direct MP3 engine is ready to be integrated into the main player as a hybrid path while retaining Preview fallback for WebM and other unvalidated formats.
