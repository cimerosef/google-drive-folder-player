## Conclusion

The bounded one-slot previous cache achieves the intended UX improvement without adding a separate previous-track preload.

Accepted behavior:

- current track plays normally;
- next track remains preloaded;
- the immediately previous track is retained as a paused cache;
- Previous can promote that cached media element directly;
- moving forward again can reuse the former current element as the next cache.

No broader playback-history cache is needed.
