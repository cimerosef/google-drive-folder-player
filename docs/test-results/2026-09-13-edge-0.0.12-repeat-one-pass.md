# Edge validation — 0.0.12 Repeat ONE PASS

Platform: Microsoft Edge + Violentmonkey
Date: 2026-09-13

## Result

Repeat ONE behaved as intended in the first 0.0.12 validation.

Confirmed behavior:

- When `Repeat: ONE` was active and the current track reached its natural end, the same queue item restarted from the beginning.
- The queue position did not advance on natural end.
- Pressing `Next now` while `Repeat: ONE` was active still advanced to the following queue item.
- This confirms Repeat ONE affects natural end-of-track handling only and does not trap manual navigation.

## Status

Repeat ONE is considered passed on Edge. Repeat ALL still needs queue-end wraparound validation before 0.0.12 can be considered fully validated.
