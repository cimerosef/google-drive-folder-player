# Edge + Violentmonkey — 0.0.19 hybrid playback PASS

Date: 2026-09-16

## Result

User validation on Microsoft Edge + Violentmonkey reports that the 0.0.19 hybrid playback build is stable and all planned behaviors matched expectations.

Validated behavior:

- MP3 tracks with stable Drive IDs use direct HTMLAudioElement playback.
- Direct MP3 playback does not open Google Drive Preview.
- MP3 -> MP3 transitions remain smooth with next-track preload.
- Mixed MP3 / WebM playback works through the hybrid boundary.
- WebM continues to use the previously validated Google Drive Preview fallback.
- WebM -> MP3 returns to direct MP3 playback after closing Preview.
- Shuffle remains functional with a fixed queue for the current run.
- Repeat ALL remains functional.
- The draggable control panel remains functional.
- Background/direct MP3 behavior remains stable during user testing.

Observed scan count in this test was 50 cached visible media items, including 43 direct-MP3-capable items. This count is **not** treated as a full-folder total: Google Drive virtual-list/full-folder discovery remains a separate future task.

## Conclusion

0.0.19 is accepted as the current stable playback baseline for the hybrid architecture:

- MP3: direct Audio + preload.
- WebM / other media: Drive Preview fallback.

The next isolated investigation can focus on whether WebM can also move to direct playback/preload without Drive Preview.
