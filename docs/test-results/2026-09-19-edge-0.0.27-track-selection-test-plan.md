# Edge + Violentmonkey — 0.0.27 track-selection test plan

Date: 2026-09-19

## Goal

Allow the user to choose any discovered track directly from the player list and start playback by double-clicking it, while preserving the accepted 0.0.26 transport/minimize behavior.

## Intended behavior

- after folder scan, the player shows the complete discovered track list in a scrollable area;
- every track row is directly selectable;
- double-clicking a track starts that track immediately;
- in ordered mode, playback continues from the selected track through the normal folder order;
- Previous / Pause-Resume / Next continue to work after starting from a selected track;
- Repeat modes continue to apply normally;
- when Shuffle is already active and no queue has yet been built, the selected track starts first and the remaining tracks are shuffled;
- the currently playing row is highlighted;
- the list preserves its scroll position when playback state refreshes;
- the compact/minimized transport bar is unchanged.

## Regression checks

1. Refresh Drive with only the 0.0.27 main userscript enabled.
2. Scan the reference Music folder and confirm all 160 tracks still appear.
3. Scroll well down the track list and double-click a track around the middle or end of the folder.
4. Confirm that exact track begins playing immediately without Drive Preview.
5. Confirm the list does not jump back to the top and the playing row is highlighted.
6. Press Previous, Pause/Resume and Next; confirm all three operate around the selected starting point.
7. Repeat the double-click test with an MP3 and a WebM.
8. Turn Shuffle ON before building a queue, double-click a chosen track, and confirm that chosen track starts first.
9. Minimize the player and confirm the compact Previous / Pause-Resume / Next controls still work.
10. Confirm background playback remains normal.

## Non-goal

0.0.27 does not add search/filtering, drag-and-drop queue editing, or persistent playlists.
