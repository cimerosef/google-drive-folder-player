# Edge + Violentmonkey — 0.0.28 mature owner PASS

Date: 2026-10-02

## Result

The owner has used 0.0.28 for many days in normal Edge + Violentmonkey use and reports that the version is mature, functionally complete for the current scope, and has shown no known bug during this extended usage period.

## Accepted Edge baseline

The accepted Edge feature set includes:

- full-folder discovery;
- complete 160-track reference-folder discovery;
- direct MP3/WebM playback without Drive Preview;
- one-track preload and smooth natural handoff;
- background playback;
- ordered and Shuffle queues;
- Repeat OFF / ALL / ONE;
- Previous / Pause-Resume / Next transport controls;
- compact minimized transport controls;
- draggable player panel;
- full selectable track list;
- double-click any track to begin playback from that track;
- live track search/filter with double-click playback;
- clear-search behavior;
- debug details kept collapsed for troubleshooting.

## Decision

Treat this exact 0.0.28 state as the mature Edge baseline.

Safari compatibility work must branch from this baseline and should preserve Edge behavior unless a cross-browser change is explicitly justified and regression-tested.
