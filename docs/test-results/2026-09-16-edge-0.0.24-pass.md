# Edge + Violentmonkey — 0.0.24 full-player PASS

Date: 2026-09-16

## Result

The integrated 0.0.24 main player passed the full regression test on Edge + Violentmonkey.

Validated behavior:

- full-folder discovery returns the complete current Music folder: 160 media files total;
- the 160-file total matches an independent manual Google Drive `Ctrl+A` count;
- composition remains 144 MP3 + 16 WebM;
- Start builds a 160-track queue;
- direct MP3 playback works without Google Drive Preview;
- direct WebM playback works without Google Drive Preview;
- MP3 -> MP3, MP3 -> WebM, WebM -> MP3 and WebM -> WebM transitions are stable;
- next-track preload remains smooth;
- natural-end advancement works;
- `Next now` works;
- Shuffle works across the full-folder queue;
- Repeat ONE works and manual Next still advances;
- Repeat ALL works;
- background playback and background handoff remain stable;
- the draggable player window still works smoothly;
- playback does not depend on the target file being currently rendered in Drive's virtualized DOM.

## Interpretation

0.0.24 successfully integrates the previously validated full-folder discovery mechanism with the previously stable unified Direct Media Core. The main functional limitation that previously capped playback to the currently rendered Drive rows is removed for the tested folder.

## Decision

PASS.

Promote 0.0.24 to `main` and freeze `stable/0.0.24`.
