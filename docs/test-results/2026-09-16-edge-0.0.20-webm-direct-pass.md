# Edge + Violentmonkey — 0.0.20 WebM direct playback PASS

Date: 2026-09-16

## Platform

- Microsoft Edge
- Violentmonkey
- Google Drive Music folder
- Probe: `probes/webm-direct-play-probe.user.js` 0.0.1

## Result

PASS.

A WebM file was captured directly from the Drive file list with a stable Drive ID. The probe then loaded the same `drive.usercontent.google.com/download` URL form already validated for MP3, using the active `authuser` index.

Observed successful media events:

- `loadstart`
- `loadedmetadata`
- `loadeddata`
- `canplay`
- `canplaythrough`
- `playing`
- `play()` resolved

The tested WebM reported a duration of about 297.5 seconds and played successfully without opening Google Drive Preview.

## Conclusion

Direct WebM playback from stable Drive ID is viable on Edge + Violentmonkey. Google Drive Preview is not intrinsically required for WebM playback. The next conservative validation step is WebM preload and WebM-to-WebM handoff before integrating direct WebM into the main player.
