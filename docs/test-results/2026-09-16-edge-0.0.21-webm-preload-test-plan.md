# Edge + Violentmonkey — 0.0.21 WebM preload test plan

Date: 2026-09-16

## Goal

Validate that two direct WebM media elements can be preloaded at the same time and handed off without Google Drive Preview, including while the Drive tab is in the background.

## Setup

1. Enable only `probes/webm-two-track-preload-probe.user.js` from branch `dev/0.0.21-webm-preload`.
2. Disable the main player and older probes.
3. Refresh the Drive Music folder.

## Foreground test

1. Click one `.webm` row and choose `Assign clicked → A`.
2. Click a different `.webm` row and choose `Assign clicked → B`.
3. Click `Preload A+B`.
4. Wait until both A and B report `canplay`.
5. Click `Play A`.
6. Click `Seek A to last 5s`.
7. Let A end naturally.

Expected:

- No Drive Preview opens.
- B starts automatically after A ends.
- The log reports `A→B audible-start latency: ... ms`.
- Playback is subjectively smooth.

## Background test

Repeat the same setup, then switch to another browser tab during A's final five seconds.

Expected:

- B starts automatically in the background.
- Playback remains normal.
- No Drive Preview is involved.

## Non-goal

This probe does not yet integrate WebM direct playback into the main player. It only validates the same preload/handoff architecture already proven for MP3.
