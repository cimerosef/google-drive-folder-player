- macOS Safari
- Userscripts
- Branch: `dev/safari-compat`

## Test

Start a WebM track whose next queue item is MP3, then allow the WebM track to end naturally without additional user interaction.

## Owner result

PASS.

The WebM ended naturally and the following MP3 track started automatically and played normally.

## Conclusion

The unchanged 0.0.28 cross-format transition path works in Safari for WebM -> MP3:

- hidden `video` end handling works;
- the preloaded `Audio` MP3 slot can be promoted;
- automatic `play()` succeeds without a new user gesture;
- mixed MP3/WebM queues can transition correctly in both directions.

Together with the prior MP3 -> WebM PASS, the current mixed-media playback architecture requires no Safari-specific compatibility layer at this stage.
