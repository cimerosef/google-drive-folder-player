# Edge + Violentmonkey — 0.0.25 UI cleanup test plan

Date: 2026-09-16

## Goal

Turn the validated 0.0.24 development panel into a compact everyday-use shell without changing the playback/discovery core.

## Intended UI changes

- rename the visible title to `Google Drive Folder Player 0.0.25` (remove `Probe` wording);
- remove the test-only `Seek last 5s` control;
- rename `Discover full folder` to `Scan folder`;
- hide `Stop discovery` unless a scan is actually running;
- shorten the explanatory text;
- keep the normal controls visible: Scan folder, Shuffle, Repeat, Start, Next, Stop;
- keep status, current playback and queue preview visible;
- move diagnostic logs into a collapsed `Debug details` section so troubleshooting capability remains available for later Chrome/Firefox/Safari work;
- preserve draggable-panel behavior.

## Regression checks

1. Refresh Drive with only the 0.0.25 main userscript enabled.
2. Confirm the compact panel mounts and can still be dragged.
3. Confirm `Stop discovery` is hidden while idle and appears while scanning.
4. Run `Scan folder`; current reference folder should still discover 160 files (144 MP3 + 16 WebM).
5. Start playback and confirm a 160-track queue is built.
6. Exercise Next, Shuffle and Repeat.
7. Confirm MP3/WebM direct playback and preload still work, including one background handoff.
8. Expand `Debug details` and confirm logs are still being collected; collapse it again.

## Non-goal

0.0.25 is a UI-only cleanup. No discovery or playback algorithm should change.
