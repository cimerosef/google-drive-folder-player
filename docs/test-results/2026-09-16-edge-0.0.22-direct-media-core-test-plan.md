# Edge + Violentmonkey — 0.0.22 direct media core probe test plan

Date: 2026-09-16

## Goal

Validate one mixed direct-media queue containing both MP3 and WebM, with one-track-ahead preload and no Google Drive Preview.

## Setup

1. Disable the 0.0.19 main player and all older probes.
2. Enable only `probes/direct-media-core-probe.user.js` from `dev/0.0.22-direct-media-core`.
3. Refresh the Drive Music folder.
4. Keep both MP3 and WebM rows visible if possible.
5. Click `Scan visible MP3+WebM`, then `Start direct queue`.

## Primary boundaries

Test these transitions when possible:

- MP3 -> MP3
- MP3 -> WebM
- WebM -> MP3
- WebM -> WebM

Use `Next now` and `Seek current to last 5s` to reach useful boundaries quickly.

Expected for every supported boundary:

- No Drive Preview opens.
- The next track is already loading/preloaded before the current track ends.
- Natural end advances automatically.
- `Next now` advances directly.
- Playback remains smooth and the log shows `Promoting preloaded track ...` when the target was ready.

## Background test

Before a mixed boundary (prefer MP3 -> WebM and WebM -> MP3), seek the current track to its last five seconds, immediately switch to another browser tab, and remain away for 10–15 seconds.

Expected:

- The next track starts and continues normally while Drive is hidden.
- Returning to Drive shows the target track in `playing` state.
- No Preview was opened in the background.

## Known non-goals

This probe intentionally does not test Shuffle, Repeat, draggable-panel integration, unsupported formats, or full-folder discovery. The current visible-row count may still be smaller than the true folder total.
