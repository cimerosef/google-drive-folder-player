# Edge + Violentmonkey — 0.0.24 main player regression plan

Date: 2026-09-16

## Goal

Validate the promoted 0.0.24 main player after integrating the already-passed full-folder discovery + direct-media queue path.

The playback/discovery core is intentionally the same validated path from the integration probe. The main-player promotion adds the established draggable panel behavior and removes the temporary tail-test button.

## Setup

1. Enable only `google-drive-folder-player.user.js` from `dev/0.0.24-full-folder-discovery`.
2. Disable the 0.0.23 main player and all standalone discovery/integration probes.
3. Refresh the Google Drive Music folder.
4. Confirm the panel title reports `Probe 0.0.24`.

## Test A — full-folder discovery

1. Click `Discover full folder`.
2. Let the automatic traversal finish without manual scrolling.

Expected:

- result is 160 items;
- breakdown is 144 MP3 + 16 WebM;
- Drive returns near the original scroll position;
- the main panel remains responsive and draggable.

## Test B — full queue

1. Keep Shuffle OFF initially.
2. Click `Start full queue`.

Expected:

- queue reports 160 tracks;
- first track starts through direct media with no Drive Preview;
- next track is preloaded.

## Test C — transition regression

Use `Next now` and `Seek last 5s` across several MP3/WebM boundaries.

Expected:

- smooth MP3 -> MP3, MP3 -> WebM, WebM -> MP3 and WebM -> WebM transitions;
- no Drive Preview;
- natural-end handoff continues after a preloaded slot is promoted.

## Test D — Shuffle / Repeat

- Shuffle ON: rebuild queue and confirm 160-track randomized queue.
- Repeat ONE: natural end repeats current track; `Next now` still advances.
- Repeat ALL: queue wraps without rebuilding the current order.

## Test E — background

While the next track is preloaded, seek current track near the end and switch to another browser tab.

Expected:

- next MP3/WebM begins normally in the background;
- no old Drive Preview delay returns.

## Test F — draggable panel

Drag the title bar to a different screen position while idle and while playing.

Expected:

- movement remains smooth;
- playback/discovery state is unaffected.

## Acceptance

If all checks pass, 0.0.24 can be promoted to `main` and frozen as `stable/0.0.24`.
