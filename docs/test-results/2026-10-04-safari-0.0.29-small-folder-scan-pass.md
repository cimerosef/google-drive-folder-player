# Safari + Userscripts — 0.0.29 small non-scrollable folder scan PASS

Date: 2026-10-04

## Environment

- macOS Safari
- Userscripts
- Branch: `dev/safari-compat`
- Player version: `0.0.29`

## Context

0.0.28 could not scan a Drive location containing only two directly visible MP3 files because the list did not overflow and therefore no scrollable Drive container could be identified.

0.0.29 adds a minimal fallback: when no scroll container exists, it performs one normal rendered-row collection pass and accepts visible supported media rows as the complete result.

## Owner result

PASS.

The test location contained exactly:

- 2 MP3 files
- 0 WebM files

The updated player returned the expected result:

- 2 tracks
- 2 MP3
- 0 WebM

## Conclusion

The non-scrollable small-folder fallback works in Safari as intended.

The next required regression check is the existing large-folder path: re-enter the Music folder and confirm the current complete count of 169 tracks is still discovered. That confirms the new fallback did not disturb the mature scroll-based discovery path.
