# Safari + Userscripts — 0.0.28 natural auto-next PASS

Date: 2026-10-04

## Environment

- macOS Safari
- Userscripts
- Branch: `dev/safari-compat`
- Player version: `0.0.28`

## Test

Allow a currently playing track to reach its natural end without pressing any playback control, and observe whether the player automatically starts the next track.

This test specifically isolates the end-event-driven automatic transition from user-initiated Next behavior.

## Owner result

PASS.

When the current track ended naturally, the next track started automatically and played normally with no additional user interaction.

## Conclusion

The unchanged 0.0.28 natural auto-next path works in the tested Safari environment:

- the current media element emits the expected `ended` event;
- the player handles `ended` correctly;
- the next preloaded/current media element can be started without a fresh user gesture;
- Safari did not reject the automatic `play()` call in this tested scenario;
- no Safari-specific autoplay/user-gesture workaround is required for natural next-track transitions at this stage.
