# Edge + Violentmonkey — 0.0.24 first full-folder discovery result

Date: 2026-09-16

## Result

The first automatic top-to-bottom discovery pass completed successfully and accumulated **160 unique stable media IDs**:

- 144 MP3
- 16 WebM
- 160 total

The Drive list initially exposed about 50 media rows. As the probe scrolled, Drive lazily expanded the rendered set in batches:

- 50 unique at the initial/top region
- 100 unique after later scrolling
- 150 unique after another lazy-load expansion
- 160 unique at the final bottom region

The final bottom settle reported no additional IDs and confirmed that the scroller remained at the bottom after Drive finished expanding its scroll range.

## Interpretation

This is strong evidence that the traversal strategy can move beyond the old ~50-row limit and collect the full lazily loaded folder contents. However, because the user does not know the folder's exact media-file count independently, **160 is provisional rather than independently verified**.

A second verifier probe was therefore added to run three traversals of the same folder (top→bottom, bottom→top, top→bottom) and compare the stable Drive-ID sets. If all three passes independently converge on the same 160 IDs, that will be treated as strong internal verification before integrating discovery into the main player.
