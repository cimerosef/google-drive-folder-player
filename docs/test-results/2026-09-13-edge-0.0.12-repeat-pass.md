# Edge validation — 0.0.12 Repeat PASS

Target: Microsoft Edge + Violentmonkey
Date: 2026-09-13

## Result

Version 0.0.12 passed the planned Repeat validation on top of the validated Shuffle + continuous-playback core.

Confirmed behavior:

- Repeat control cycles through OFF -> ALL -> ONE -> OFF.
- Repeat ONE restarts the naturally finished current track from the beginning without changing queue position.
- Manual `Next now` still advances to the following queue item while Repeat ONE is active.
- Repeat ALL wraps from the final queue item back to item 1 after a natural track ending.
- `Next now` from the final queue item also wraps to item 1 while Repeat ALL is active.
- Repeat ALL also passed while Shuffle was enabled; the existing shuffled queue was reused rather than regenerated.
- MP3/WebM playback, hidden WebM progress detection, automatic end detection, Shuffle behavior, transition reliability, and transition speed remained stable.

## Conclusion

0.0.12 is considered validated on Edge + Violentmonkey for Repeat OFF / ALL / ONE over the currently cached media queue.

The next change should be isolated from playback logic. A draggable diagnostic/player panel is a suitable UI-only follow-up so the overlay does not block Drive's seek bar during testing and use.
