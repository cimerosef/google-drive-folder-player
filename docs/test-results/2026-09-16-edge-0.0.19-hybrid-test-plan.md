# Edge + Violentmonkey — 0.0.19 hybrid playback test plan

Date: 2026-09-16

## Goal

Validate the first integrated hybrid playback build without changing full-folder discovery.

- MP3 with stable Drive ID -> direct HTMLAudioElement playback.
- Next MP3 -> preloaded direct Audio and smooth promotion.
- WebM / other media -> existing Google Drive Preview fallback.
- Shuffle, Repeat and draggable panel remain available.
- The scan is still intentionally limited to currently rendered/cached Drive rows.

## Setup

1. Enable only `google-drive-folder-player.user.js` from branch `dev/0.0.19-hybrid-playback-core`.
2. Disable the standalone direct-MP3 probes and older playback probes.
3. Refresh the Drive Music folder.
4. Keep a mixed set of MP3 and at least one WebM visible if possible.

## Test A — MP3 -> MP3

1. Click `Scan folder view`.
2. Start hybrid playback on an MP3.
3. Confirm the status shows `Engine: DIRECT MP3`.
4. Wait until the status reports `next preloaded`, or use `Next now` after the next MP3 is ready.
5. Repeat across several MP3 tracks.

Expected:

- No Drive Preview opens for MP3.
- MP3 -> MP3 transitions are smooth.
- Queue marks MP3 rows as `[MP3]`.
- Background playback remains stable.

## Test B — MP3 -> WebM

Advance from a direct MP3 to a WebM item.

Expected:

- Direct MP3 audio stops.
- Drive Preview opens only for the WebM.
- Status changes to `Engine: DRIVE PREVIEW`.
- WebM plays through the previously validated Preview path.

## Test C — WebM -> MP3

Let the WebM finish naturally or use `Next now` to reach an MP3.

Expected:

- Drive Preview is closed.
- The target MP3 starts through direct Audio.
- Status returns to `Engine: DIRECT MP3`.
- If the MP3 was preloaded while WebM was playing, the log should show promotion of a preloaded direct MP3.

## Test D — Shuffle / Repeat smoke test

- Shuffle ON: queue order stays fixed after Start and MP3 entries continue to use direct Audio.
- Repeat ONE on MP3: natural end restarts the same direct Audio track; `Next now` still advances.
- Repeat ALL: queue wraps without rebuilding the shuffle order.

## Test E — background smoke test

While an MP3 is playing with another MP3 preloaded, switch to another browser tab before natural end.

Expected:

- Next MP3 begins in the background without Drive Preview.
- No long Preview transition delay returns for MP3 -> MP3.

## Known non-goal

This build does **not** solve Google Drive virtual-list/full-folder discovery. A count smaller than the real folder total is not a failure for 0.0.19.
