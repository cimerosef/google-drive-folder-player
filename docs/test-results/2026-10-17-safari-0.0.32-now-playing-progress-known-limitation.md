# Safari + Userscripts — 0.0.32 Now Playing progress known limitation

Date: 2026-10-17

## Result

The 0.0.32 A/B experiment did not resolve macOS Now Playing progress.

Owner result:

- current track title remains available in macOS Now Playing;
- system Previous / Play-Pause / Next controls remain usable;
- cross-application media-key control remains the intended supported behavior;
- macOS Now Playing progress remains frozen / stale.

## Comparison

0.0.31:
- explicit `MediaSession.setPositionState()` updates;
- progress frozen.

0.0.32:
- no explicit position injection;
- WebKit allowed to own timing from the active HTMLMediaElement;
- progress still frozen.

Therefore the stale progress display is not caused solely by the player's explicit position synchronization.

## Decision

Accept the current behavior as a known Safari/macOS system-media limitation for this userscript architecture.

Do not modify the mature direct-media / preload architecture merely to improve a cosmetic system progress indicator.

Accepted Media Session functionality:

- current track metadata/title in macOS Now Playing;
- Play/Pause media-key control;
- Previous Track media-key control;
- Next Track media-key control;
- operation while another application is foregrounded.

Known limitation:

- macOS Now Playing progress may remain stale/frozen.

0.0.32 remains the simpler candidate because it avoids unnecessary custom position-state synchronization while preserving the useful system-control behavior.
