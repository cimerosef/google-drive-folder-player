# Safari + Userscripts — 0.0.32 native Now Playing progress test plan

Date: 2026-10-17

## Goal

Keep the successful 0.0.31 Media Session ownership and control routing, but stop overriding progress through `MediaSession.setPositionState()`.

## Rationale

0.0.31 achieved:

- cross-application Mac media-key control;
- reliable Previous / Play-Pause / Next routing;
- current track title in macOS Now Playing.

The only remaining issue was stale/frozen Now Playing progress.

WebKit already derives Now Playing timing from the active HTMLMediaElement and periodically refreshes current time. 0.0.32 therefore removes explicit playback-position injection while retaining metadata and action handlers.

## Changes

Removed only:

- explicit `setPositionState()` updates during playback;
- periodic position refresh logic tied to `timeupdate`.

Retained:

- Media Session action handlers;
- metadata assignment before playback;
- metadata reassertion on playback events;
- playbackState synchronization;
- all direct-media / preload / queue / discovery logic.

## Static verification

JavaScript syntax: PASS.

## Safari acceptance test

1. Update Userscripts to 0.0.32 and refresh Google Drive.
2. Start a known track.
3. Open macOS Now Playing.
4. Confirm title still appears.
5. Keep the panel open at least 10–15 seconds and observe whether the progress advances.
6. Verify Play/Pause, Next and Previous still work.
7. Put another app in the foreground and verify media-key control still works.

Success criteria:

- metadata remains correct;
- progress advances normally;
- cross-application media-key control is preserved.
